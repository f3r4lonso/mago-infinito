# Arte faltante

Prompts para generar con IA todo el arte que el juego todavía dibuja por código (círculos, líneas, partículas) y para rehacer los sprites de los héroes con un estándar único.

| Archivo | Contenido |
|---|---|
| `animaciones-faltantes.md` | Un prompt pequeño por animación de habilidad que hoy es vectorial (mago, alquimista, orco, nigromante, druida, hombre lobo, monje, troll, enano, chamán, sacerdote, caballero dragón, cazador, devorador y arquero), con un PREFIJO común. |
| `sprites-heroes-unificados.md` | Especificación técnica y prompt base para rehacer los 16 héroes: misma celda, misma línea del suelo, alturas proporcionales y las mismas 9 animaciones (más el set de forma transformada). |

Reglas comunes: diseños originales sin citar juegos, fondo magenta `#FF00FF`, celdas iguales sin solaparse, sin sombras de suelo ni texto.

Referencia: los prompts de efectos de otras hojas están en `prompts-efectos/faltantes/` y los del alquimista en `prompts-heroes/`.
