# Alquimista: animaciones de habilidades (3 por imagen)

Una imagen por grupo: **6 columnas x 3 filas**, cada fila es una habilidad con 6 fotogramas de izquierda a derecha. Cada habilidad tiene su propio color para que no se repitan. El ogro verde no aparece (son solo efectos).

Si el generador no respeta las 3 filas, genera cada fila por separado cambiando 'each row is ONE effect' por 'one row of 6 frames'.

## Grupo 1: Frasco corrosivo, Aceite inflamable, Chispa reactiva  (556 caracteres)

```
Game effect animation sprite sheet, 6 columns x 3 rows, each row is ONE effect in 6 frames left to right, same size and center in every frame, magenta #FF00FF background, thick dark-purple outline, cartoon, no text, no characters. Row 1 LIME-GREEN acid: small drop, splash starts, big splash with drops, spreading puddle, bubbling puddle, fading puddle. Row 2 AMBER-BROWN oil: falling drops, splash, big splash, spreading, glossy puddle, shimmering puddle. Row 3 ORANGE-RED fire: small spark, fireball, explosion starts, big explosion, dying flames, smoke.
```
Recorte: `al_flask_1-6, al_oil_1-6, al_spark_1-6` (fila 1, 2 y 3, en ese orden)
